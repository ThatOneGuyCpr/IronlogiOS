# Theme fonts

Latin subsets of open-source fonts used by the themes, converted to TTF with
internal names prefixed `IL-` so they never clash with system fonts.

All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):
Press Start 2P, VT323, UnifrakturMaguntia, Playfair Display, Source Serif 4,
Libre Franklin, JetBrains Mono, Archivo Black, Archivo, Pixelify Sans, Silkscreen,
Anton, Oswald, Barlow Condensed, Passion One, Yellowtail, Rubik.
